# Aura AI — Especificación de Arquitectura de Software
**Autor:** Yamir Vera (Universidad Veracruzana (UV Xalapa))

## 1. Visión General
Aura AI es un sistema cognitivo autónomo full-stack implementado en TypeScript y React, diseñado para actuar como mentora, ingeniera de software y copiloto de ciencia de datos.

## 2. Componentes Fundamentales
1. **Motor Neuroquímico / Emocional**:
   - Simulación probabilística de dopamina, serotonina, oxitocina y cortisol.
   - Modulación adaptativa del tono y estilo de respuesta.

2. **Pool de Cuotas Multinivel**:
   - Conmutación dinámica de 20 slots de API Keys con algoritmos de backoff exponencial.

3. **Sandbox de Ejecución Aislada**:
   - Virtualización de canvas 2D para renderizado seguro de videojuegos y simuladores de física.

4. **Integración Cinéfila**:
   - Referencias narrativas estructuradas (*Breaking Bad, Rick & Morty, BoJack Horseman, Taxi Driver, Oldboy, WALL-E*).
