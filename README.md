## 🚀 Despliegue Rápido en GitHub Pages

Para publicar este portafolio en tu propio GitHub en menos de 2 minutos:

```bash
# 1. Clona o inicializa el repositorio
git init
git add .
git commit -m "feat: Initial release of Yamir Vera Data Science & Retro Games Portfolio"

# 2. Conecta con tu repositorio en GitHub
git branch -M main
git remote add origin https://github.com/yamirvera/portafolio.git
git push -u origin main
```

Luego ve a **Settings > Pages** en GitHub y selecciona la rama `main` y carpeta `/ (root)`.
